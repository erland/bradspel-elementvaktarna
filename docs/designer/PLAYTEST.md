# Playtestguide

## Syfte

Testa om spelets kärnloop, kristalltempo och bosskamp fungerar för målgruppen.

## Mätvärden

- total speltid
- antal rundor
- mörkernivå vid spelets slut
- antal hittade kristaller
- antal misslyckade strider
- hur ofta varje platsförmåga används
- vilka regler som behöver förklaras

## Observationer

- Förstår spelarna vad de får göra på sin tur?
- Vet de hur kristaller hittas?
- Förstår de när bossen kan skadas?
- Är någon hjälte tydligt starkare?
- Blir väntetiden mellan turerna för lång?

## Efter test

Ändra högst tre saker. Dokumentera varför varje ändring görs.
