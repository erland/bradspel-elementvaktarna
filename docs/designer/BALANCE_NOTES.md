# Balansanteckningar

## Att följa upp

- vinstfrekvens per spelarantal
- genomsnittlig mörkernivå vid seger
- genomsnittligt antal turer till fjärde kristallen
- energiförlust per hjälte
- antal bossanfall per parti

## Ändra inte ännu

- hjälteförmågornas grundidé
- kartans kopplingar
- antal elementplatser
